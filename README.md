# Website_GUN - Công ty TNHH Gia Uy Nguyễn (giauynguyen.vn)

## Cấu trúc thư mục (Khuyến nghị lưu tại C:\Website_GUN)
- `index.html`: Trang chủ và điều hướng đa trang song ngữ (VI / EN)
- `css/style.css`: Định dạng giao diện theo bộ nhận diện V2b
- `js/app.js`: Logic điều hướng, chuyển đổi ngôn ngữ VI/EN, dữ liệu sản phẩm/bài viết và biểu mẫu
- `assets/images/`: Logo chính thức phương án V2b (nền sáng & nền tối)
- `data/products_template.json`: Mẫu cấu trúc JSON để quản lý và bổ sung danh mục sản phẩm

## Triển khai nhanh
Thư mục `Website_GUN` là bộ mã nguồn tĩnh (Static Web), có thể tải trực tiếp lên Cloudflare Pages hoặc Vercel với chi phí 0 đồng/tháng và trỏ tên miền `giauynguyen.vn`.
